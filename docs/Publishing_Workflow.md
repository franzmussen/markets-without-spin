
# Markets Without Spin Publishing Workflow

## Purpose

This document defines the standard process for publishing articles on the Markets Without Spin website.

The objective is consistency. Every episode should follow the same workflow and use the same page structure.

---

## Website Philosophy

- Markets Without Spin is a permanent library of evergreen investment essays.
- It is not a chronological blog.
- Every podcast episode has one corresponding essay.
- The essay is the canonical version of the content.
- The podcast page and essay represent the same material.

---

## Standard Publishing Workflow

1. Write the article in Microsoft Word.
2. Bring the article into ChatGPT for editing and formatting.
3. Generate a single v0 prompt using the established website architecture.
4. Paste the prompt into v0.
5. Review the preview.
6. Merge the pull request.
7. Verify the production site.

---

## Every Article Includes

- Title
- Subtitle
- Editor's Note
- Main article
- Key Takeaways
- Final Thoughts
- Embedded podcast player
- Related Reading
- Previous / Next navigation
- SEO title
- Meta description
- Open Graph description

---

## Design Rules

Do not redesign the website unless specifically requested.

Do not change:

- navigation
- typography
- colors
- spacing
- layout
- reusable components

New articles should use the same design and content model as existing articles.

---

## Future Goal

Publishing a new episode should require only:

1. Writing the article.
2. Having ChatGPT generate the publication prompt.
3. Pasting the prompt into v0.
4. Reviewing and merging.

No custom prompt engineering should be necessary for each new episode.
